---

### Design-Überlegungen

| Prinzip                                    | Grund                                          |
| ------------------------------------------ | ---------------------------------------------- |
| **DiaryEntry is the root unit**            | Preserves historical context across pages      |
| **ObservationEvent is a first-class node** | Enables Darwin Core / DwC-A export             |
| **SourceReference on every entity**        | Full traceability to image coordinates         |
| **Place linked to authority files**        | GeoNames, TGN, historical gazetteers           |
| **Taxon linked to authority files**        | Catalogue of Life, GBIF Backbone               |
| **Person linked to authority files**       | GND, VIAF, Wikidata                            |
| **Uncertainty is modelled explicitly**     | Transcription confidence, reading alternatives |

### Ontology Namespaces

```text
hist:DiaryEntry        →  project ontology
hist:ObservationEvent  →  project ontology + dwc:Occurrence
hist:Place             →  owl:sameAs geonames:, tgn:
hist:Taxon             →  owl:sameAs gbif:, col:
hist:Person            →  owl:sameAs gnd:, viaf:, wikidata:
hist:SourceReference   →  oa:Annotation (W3C Web Annotation)
```

# Entity Recognition Workflow


---

### The Full Agent Pipeline

```
  ┌──────────────────────────────────────────────────────────────────┐
  │  PAGE IMAGE                                                       │
  └──────────────────────────┬───────────────────────────────────────┘
                             │
                    ┌────────▼────────┐
                    │   AGENT 1       │
                    │ Entry Detection │  → segments page into
                    │                 │    individual DiaryEntry units
                    └────────┬────────┘
                             │  DiaryEntry + bounding box + page ref
                    ┌────────▼────────┐
                    │   AGENT 2       │
                    │ Transcription   │  → handwriting → raw text
                    │ + Normalisation │    original wording preserved
                    └────────┬────────┘
                             │  raw text + confidence score
                    ┌────────▼────────┐
                    │   AGENT 3       │
                    │ Entity          │  → detects:
                    │ Recognition     │    Date / Place / Species /
                    │                 │    Person / Quantity / Behaviour
                    └────────┬────────┘
                             │  entity spans + types + uncertainty flags
                    ┌────────▼────────┐
                    │   AGENT 4       │
                    │ Entity Linking  │  → maps to:
                    │                 │    GBIF / GeoNames / GND / Wikidata
                    └────────┬────────┘
                             │  linked entities + confidence + alternatives
                    ┌────────▼────────┐
                    │   AGENT 5       │
                    │ Relation        │  → builds:
                    │ Extraction      │    ObservationEvent triples
                    └────────┬────────┘
                             │  structured RDF / JSON-LD
                    ┌────────▼────────┐
                    │   AGENT 6       │
                    │ Ontology        │  → validates against
                    │ Validation      │    ontology constraints
                    └────────┬────────┘
                             │  validated triples
                    ┌────────▼────────┐
                    │   AGENT 7       │
                    │ KG Export       │  → JSON-LD / RDF / DwC-A
                    └─────────────────┘
```

---

### What Each Agent Produces

| Agent | Input | Output | Ontology Class |
|---|---|---|---|
| **1 Entry Detection** | Page image | Entry regions + coordinates | `hist:DiaryEntry` |
| **2 Transcription** | Entry image crop | Raw text + confidence | `hist:SourceReference` |
| **3 Entity Recognition** | Normalised text | Typed entity spans | `Date` `Place` `Species` `Person` |
| **4 Entity Linking** | Entity spans | URIs + match confidence | `owl:sameAs` links |
| **5 Relation Extraction** | Linked entities | Structured relations | `hist:ObservationEvent` |
| **6 Validation** | RDF graph | Validated / flagged triples | Ontology constraints |
| **7 KG Export** | Validated graph | JSON-LD · RDF · DwC-A | Final KG |

---

### Concrete Example Through the Pipeline

```
  PAGE IMAGE  →  Entry detected: "17. Mai 1884, Leipzig"
       ↓
  TRANSCRIPTION  →  "3 singende Amseln am Morgen beobachtet"
       ↓
  ENTITY RECOGNITION
       Date     →  "17. Mai 1884"
       Place    →  "Leipzig"
       Species  →  "Amseln"
       Quantity →  "3"
       Behaviour→  "singend"
       ↓
  ENTITY LINKING
       Species  →  gbif:5789117  (Turdus merula)
       Place    →  geonames:2879139  (Leipzig)
       ↓
  RELATION EXTRACTION
       ObservationEvent_001
         dwc:eventDate        →  1884-05-17
         dwc:locality         →  "Leipzig"
         dwc:scientificName   →  "Turdus merula"
         dwc:individualCount  →  3
         hist:behaviour       →  "singing"
         hist:sourceEntry     →  DiaryEntry_001
       ↓
  KG EXPORT  →  RDF triple store + DwC-A occurrence record
```
