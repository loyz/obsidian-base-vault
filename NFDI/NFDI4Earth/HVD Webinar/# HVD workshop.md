## **TIER 1: EU-LEVEL PORTALS**

### **1. data.europa.eu (European Data Portal)**
- **URL:** https://data.europa.eu/
- **Search by HVD Tag:** ✅ **YES** - Filter available: `is_hvd=true`
- **Categories Covered:** Geospatial, Earth Observation & Environment, Meteorological, Statistics, Companies, Mobility
- **Features:** 
  - HVD Dashboard (beta version) organized by categories per Commission Implementing Regulation (EU) 2023/136
  - HVD Reporting Tool for Member States
  - Search guide with dedicated HVD filters
  - Machine-readable formats required
- **ESS Relevance:** ⭐⭐⭐⭐⭐ (Primary EU source for HVDs)

### **2. Copernicus Climate Data Store (CDS)**
- **URL:** https://cds.climate.copernicus.eu/
- **Search by HVD Tag:** ✅ **YES** - Integrated HVD support
- **Categories Covered:** Climate datasets, meteorological data, Earth observation
- **Features:**
  - Searchable catalogue with advanced filtering
  - Online toolbox for workflow building
  - API access to full data store catalogue
  - Supports EU Open Data Directive compliance
- **ESS Relevance:** ⭐⭐⭐⭐⭐ (Flagship for climate/meteorological HVDs)

## **TIER 2: NATIONAL OPEN DATA PORTALS**

- **Search by HVD Tag:** ✅ **YES** - "hvd" tag with thematic sub-tags

- **ESS Relevance:** ⭐⭐⭐ (National example of HVD tagging)
