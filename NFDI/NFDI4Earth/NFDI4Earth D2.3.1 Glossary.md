Accessibility / Accessible (FAIR): In the context of FAIR, the property that (meta)data can be retrieved by humans and machines via standardized protocols, with clear access conditions (including authentication/authorization). 

Aggregator / Metadata Aggregator: A service that collects metadata from multiple providers, often including harmonization and quality assessment. Collected data are usually made available via APIs for redistribution to downstream portals and catalogues and for harvesting. 

API: Application Programming Interface. Reference: BSI Glossary https://www.bsi.bund.de/DE/Themen/Oeffentliche-Verwaltung/Moderner-Staat/ElektronischeSignatur/Glossar/esigglossar.html?nn=450092#Glossar_A (last-visited: 2026-03-20)

ATOM Feed: Refers to the Atom Syndication Format (ASF), an XML standard used for web feeds. In ESS, this IETF registered standard is also used for structured download of geodata tiles. BKG (Bundesamt für Kartographie und Geodäsie): Federal Agency for Cartography and Geodesy. Reference: BKG official website. [https://www.bkg.bund.de/](https://www.bkg.bund.de/DE/Das-BKG/Wir-ueber-uns/wir-ueber-uns.html) (last-visited: 2026-03-20)

BDSG (Bundesdatenschutzgesetz): Federal Data Protection Act. Reference: Gesetze im Internet – BDSG. https://www.gesetze-im-internet.de/bdsg_2018/ (last-visited: 2026-03-20)

CSW: Catalogue Service for the Web. Reference: OGC standard page “Catalogue Service Standard”. https://www.ogc.org/standards/cat/  or https://docs.ogc.org/is/12-168r6/12-168r6.html(last-visited: 2026-03-20)

Catalog / Catalogue (Metadata Catalogue): Structured collection of metadata records describing datasets and services, usually searchable via a web interface and/or an API. Reference: GDI-DE. https://www.gdi-de.org/ (last-visited: 2026-03-20)

CKAN (Comprehensive Knowledge Archive Network): Software used by the GovData catalogue and by other national and regional government organizations in the EU. Reference: CKAN project site. https://ckan.org/ (last-visited: 2026-03-20)

Controlled Vocabulary: A curated set of standardized terms (often with identifiers) used in metadata to ensure consistent tagging, making targeted search more efficient. Reference: W3C SKOS Recommendation (core standard used for controlled vocabularies in RDF contexts). https://www.w3.org/TR/skos-reference/ (last-visited: 2026-03-20)

CSW (Catalogue Service for the Web): OGC standard for publishing and querying geospatial metadata catalogues; a CSW interface is commonly used for harvesting ISO-based metadata. Reference: OGC standard page “Catalogue Service Standard”. https://www.ogc.org/standards/cat/ (last-visited: 2026-03-20)

DCAT: Data Catalog Vocabulary. A W3C vocabulary (RDF-based) for describing datasets and data services in catalogues. Reference: W3C Recommendation “Data Catalog Vocabulary (DCAT) – Version 3”. https://www.w3.org/TR/vocab-dcat-3/ (last-visited: 2026-03-20)

DCAT-AP: Data Catalog Vocabulary Application Profile that specifies required fields and conventions for interoperable metadata exchange. There is a German derivative (DCAT-AP.de) of the European standard. FAIR Principles (Findable, Accessible, Interoperable, Reusable): Guiding principles designed to improve (meta-)data management and stewardship, making data more fit for scientific purposes. Reference: GO FAIR – FAIR Principles. https://www.go-fair.org/fair-principles/ (last-visited: 2026-03-20)

Findable (FAIR): FAIR property that data and metadata can be discovered via searchable metadata, stable identifiers, and indexing.

GeoZG (Geodatenzugangsgesetz): Geodata Access Act. Reference: Gesetze im Internet – GeoZG. https://www.gesetze-im-internet.de/geozg/ (last-visited: 2026-03-20)
